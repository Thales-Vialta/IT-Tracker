## **1\. Visão Geral e Objetivos do Projeto**

O Projeto Piloto Integrado consiste no desenvolvimento de um sistema de software que tem como propósito central integrar os diversos componentes curriculares estudados ao longo do curso de ADS, com foco especial nas disciplinas cursadas até o 3º período.  
A atividade visa provocar uma mudança de postura no discente, estimulando-o a migrar do papel tradicional de aluno para atuar sob a perspectiva profissional de um **Desenvolvedor de Software Jr.** Para isso, o projeto exige que os estudantes proponham análises, reflexões e soluções relacionadas a uma temática central, identificando problemas reais para pesquisar, conceber e construir protótipos (ainda que parciais) que representem soluções tecnológicas viáveis.

## **2\. Escopo Técnico da Temática Central**

O núcleo do projeto consiste no desenvolvimento de um Sistema de Software Web que utilize tecnologia de banco de dados e seja gerenciado por meio do método ágil Scrum. É permitida a reutilização de projetos já desenvolvidos ou em desenvolvimento em outras disciplinas da grade curricular.

### **Diretrizes de Implementação de Interface:**

* **Aplicações Web:** Destinadas aos alunos que já detêm conhecimento prévio e domínio de desenvolvimento para a Web.  
* **Aplicações Desktop:** Permitidas como alternativa para os alunos que ainda não adquiriram os conhecimentos de Web. Para este grupo, serão fornecidos tutoriais específicos de conexão com Banco de Dados SQL.

| Requisitos Técnicos Gerais | Requisitos Técnicos Específicos   |
| :---- | :---- |
